# Task Sims

**Neuroscience experiments you can play, in your browser:** https://lustigb.github.io/tasksims/

Each sim rebuilds the apparatus of a published rodent experiment, to scale, from the paper's methods and
figures, and lets you be the animal. One build holds them all; the link picks which one opens:

`https://lustigb.github.io/tasksims/?maze=<name>`

| `?maze=` | Experiment |
|---|---|
| (none) | TADS: three-arm delayed sequence task (Lustig et al.) |
| pfeiffer | Pfeiffer & Foster 2013: open-arena HOME / RANDOM task |
| akrami | Akrami et al. 2018: auditory parametric working memory |
| fortin | Fortin et al. 2002: odour sequence memory |
| pastalkova | Pastalkova et al. 2008: wheel-run delayed alternation |
| kraus | Kraus et al. 2013: treadmill figure-8 alternation |
| wikenheiser | Wikenheiser & Redish 2015: circular track with delayed feeders (setup) |
| honeycomb | Wood et al. 2018: honeycomb maze of rising platforms |
| manhattan | Zheng et al. 2026: Manhattan Maze, two-layer mouse labyrinth with swappable masks |
| miller | Miller et al. 2017: rat two-step task (setup) |
| zugaro | Drieu et al. 2018: rat on a model train (setup) |
| widloski | Widloski & Foster 2022: arena with changing barriers (setup) |
| grima | Grima et al. 2026: mouse multi-site foraging arena (setup) |
| rich | Rich et al. 2014: 48 m giant track (setup) |
| karlsson | Karlsson & Frank 2009: two W-tracks and a rest box (setup) |
| wtrack | Frank lab W-track (setup) |
| davidson | Davidson et al. 2009: 10 m linear track (setup) |
| xu | Xu et al. 2019: radial 8-arm maze (setup) |
| gillespie | Gillespie et al. 2021: eight-arm maze (setup) |

Works on a laptop (keyboard and mouse; press **H** for the controls) and on a phone (touch controls; hold
the phone sideways). Everything here is still in development. The finished TADS game is at
https://lustigb.github.io/rattadstask/. More about the project: https://lustigb.github.io/site-preview/project-task-sims.html

Built with the Godot game engine. This repository holds only the exported web build.
